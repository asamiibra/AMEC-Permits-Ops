# E1 safety boundary

E1 is metadata, relational semantics, seed data, and read-only inspection APIs. It does not send email, release quotations, execute contracts, issue invoices, write accounting, approve engineering, release handovers, write government systems, expose generic browser credentials, or submit permits.

Seeded records are deliberately `DRAFT`, `NOT_APPROVED`, `TRACK_ONLY`, `NOT_READY`, `HUMAN_REVIEW_REQUIRED`, `SYNTHETIC_PLACEHOLDER`, or `SYNTHETIC_STANDIN` where appropriate. The Stage 2 disposition remains `UNDECIDED_STAGE2` and no record claims client approval.
