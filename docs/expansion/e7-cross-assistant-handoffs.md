# E7 cross-assistant handoffs

Handoffs preserve context type/id, source revisions, project/opportunity linkage, reason, and task linkage. Acceptance is explicit and audited. No assistant may self-escalate or silently transfer authority.
# E7 cross-assistant handoffs

Handoffs are explicit records with source assistant, target assistant, context type/id, project or opportunity truth, source revision IDs, correlation, audit events, and a linked `WorkflowTask`. Acceptance is a separate human-controlled transition. The acceptance rehearsal covers BD → Admin → Project/Permit → Engineering and returns through Project/Permit, plus finance/handover-compatible shared project context.
