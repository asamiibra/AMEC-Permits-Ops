# E7 assistant capability map

The canonical set is exactly `BD_ASSISTANT`, `ADMIN_ASSISTANT`, `ENGINEERING_REVIEW_ASSISTANT`, and `PROJECT_PERMIT_COORDINATION_ASSISTANT`. The implemented minimum mapping is:

- BD: RFQ intake, opportunity review, BD checklist, quotation field review, quotation preparation, commercial review handoff, client response tracking.
- Admin: contract preparation/review handoff, client checklist, missing-document follow-up, contract milestones, municipality form preparation, reference preparation, communication draft.
- Engineering: engineering review preparation, regulation applicability, advisory analysis, engineer comment review, comment-sheet preparation, drawing revision review, block-time tracking.
- Project/Permit: reference assignment, project bootstrap, Synology link, project status, admin document review, system-block management, permit handoff/coordination, authority-change follow-up, finance handoff, project handover.

All capability rows remain `UNDECIDED_STAGE2`, `DRAFT`, `PROTOTYPE_DEV_ONLY`, and disabled in production.
