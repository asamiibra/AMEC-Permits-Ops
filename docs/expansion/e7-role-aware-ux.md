# E7 role-aware UX

The UI exposes `Demo as` in synthetic mode, identifies assistant lens and owner role, surfaces blockers, and displays human-authority badges. UI labels do not grant professional, commercial, accounting, or government authority.
# E7 role-aware UX

The UI offers assistant and owner-role lenses over the same queue. Synthetic builds display `DEMO AS · SYNTHETIC ONLY`; production-like role switching is denied unless an authenticated identity/RBAC context is present. A lens changes visibility, not canonical ownership or stored truth.
