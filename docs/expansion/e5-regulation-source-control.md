# E5 regulation source control

Regulation sources and versions carry publication/content state. Only `APPROVED_FOR_TEST` and `APPROVED_CONTROLLED_SOURCE` can support a trusted synthetic advisory run. `SYNTHETIC_PLACEHOLDER` is mechanics-only; `UNVERIFIED_DO_NOT_USE_FOR_AUTHORITY`, superseded, or revoked content blocks trusted execution. Retrieval is bounded to the pinned drawing, approved project evidence, and the selected controlled versions; open-web retrieval is disabled.
