# Unified Proposal workspace

The canonical detail route remains one Proposal identity. The page now makes the Owner concepts visible as organized sections: Sources; Client & Contact; Site / Property; Client Request; Engineering Preparation; Commercial; Proposal Breakdown; Information & AMEC Input; Readiness / Authority Review; Accept / Outputs; and History.

Current Stage, Current Owner, and Next Action remain projection values. BD and Engineering share the route. Server-side edit authority permits Engineering technical preparation fields (`scope_of_work`, `sow`, `process_of_work`, technical assumptions/deliverables) through `EDIT_TECHNICAL`, while commercial/client/source/Accept controls remain BD-authorized.
