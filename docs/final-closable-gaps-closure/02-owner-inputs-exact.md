# Exact Owner Inputs

1. Select and approve the Golden Service and its official authority/service/source set.
2. Confirm official current Proposal, Contract, Handover, Completion, Building Statistics, Materials Conformity, Site Cleanliness, and authority-form sources, including currentness and retention.
3. Confirm workflow policy: Accept Proposal, Proposal→Contract, contract authority/evidence, amount-change authority, Project Activation, Project Code, Start Date, Engineering approval, Handover, Service Scope Close, Financial Settlement, Regulatory Closeout, archive/retention.
4. Provide named production users, roles, MFA/IdP provisioning, and special approval capability assignments.
5. Confirm production database/provider/region/secrets/backup policy and authorize a live backup-restore rehearsal.
6. Provide or authorize production deployment provenance/current SHA access and sign off application handover.
7. Complete Owner/BD/Engineering UAT, training acknowledgment, Owner application-handover acknowledgment, and explicit production GO or GO_WITH_CONDITIONS.

These are decisions, authoritative inputs, or access only an authorized AMEC human can provide.
