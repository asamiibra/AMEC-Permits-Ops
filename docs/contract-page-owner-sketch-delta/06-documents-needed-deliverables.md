# Documents Needed and Deliverables

Documents Needed is a structured Contract view over `ContractClientInputRequirement`. Deliverables is a structured Contract view over `ContractDeliverableCommitment`. Both display requiredness/status and remain distinct from regulatory requirement instances, permit attachments, engineering drawing deliverables, and downstream project work.

Existing Contract add commands remain the write path. The page does not create a regulatory requirement, engineering task, BillingMilestone, Invoice, or Payment from these lists.
