# Contract Documents and Sources

The compact source panel contains exactly six visible entries: Contract, Document List, Accepted Proposal, LPO, Client Document, and Contract Template. Each entry shows a human-readable detail, source domain, and an exact open action when available. Technical identifiers are kept in API evidence rather than normal Owner labels.

The panel is a projection, not a second source of truth. It links back to the Contract revision, `ContractClientInputRequirement`, accepted Proposal revision, exact DocumentVersion, and Dashboard master content.
