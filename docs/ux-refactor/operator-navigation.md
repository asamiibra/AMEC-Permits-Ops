# Operator navigation

My Work is the default `/work` landing page. Its cards derive from projects/applications, findings, tasks, notifications, readiness, and monitoring signals. It is not a manually maintained queue.

Permits is `/permits` and includes filters for all permits, needs action, authority review, and ready/closed. Each row opens the projected current stage. Reviews, Issues, and Notifications are global views that deep-link back to the permit context.
