# Permit workspace

`/permits/:projectId/:stage` renders the permit header, application identity, current status, owner/next actor, lifecycle stepper, breadcrumb, Next Action card, and stage-specific content. Stage buttons change the view only; they do not advance state.

The final review surface explicitly says PermitOps cannot submit the application and provides only readiness, handoff, and confirmation routes. History separates current from historical evidence and links technical lineage contextually.
