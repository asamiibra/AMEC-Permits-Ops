# Classification and taxonomy

Category remains an Owner-managed business classification. Engineering Source Type is a separate persisted field with the controlled values Regulation, QCS, Municipality Comment, Authority Guidance, Engineering Standard, Design Guide, Technical Reference, and Other. Discipline remains a separate metadata value with General, Design, Architecture, Structural, Civil, MEP, Fire & Life Safety, Permit, and Other.

Existing categories, references, versions, and consumer snapshots are preserved. New categories may be created or updated only through the Owner/System Admin category endpoints. No speculative fifth library was introduced.
