# Controlled Excel Projection Contract

The recording-derived workbook retains `GENERAL FOLLOW UP`, `DESIGN`, `Suppervission`, and `Services Provider`. Week 4 projection records workbook/sheet/row/column, ownership, rendered value, source assertion, rule version, and status. `PERMITOPS_OWNED` writes are allowed; human-owned writes return `EXCEL_PROJECTION_BLOCKED_OWNERSHIP`; lock failures return a controlled exception.
