# Evidence-to-prefill lineage proof

The governed path is:

`governed_retrieve()` → exact current Master Content form/version pin →
deterministic consumer resolver/binding → AuthorityCase prefill preview →
existing human/domain command.

The preview returns the form template `MasterContentItem` and exact template
`DocumentVersion` separately from each proposed field's `SemanticValueAssertion`
source. Document-backed assertions resolve to the exact current evidence
`DocumentVersion`, hash, observation/verified-assertion identity, and locator.
Unverified, stale, cross-project, unsupported, or conflicting evidence cannot
produce a READY field. The preview has zero canonical writes and defers the
existing safe apply/human command seam.
