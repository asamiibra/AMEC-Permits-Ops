# Page-header system

The canonical header is:

`[optional compact context]  Page title  [page-level action]`

followed by concise supporting copy only where it helps the operator. The global shell now identifies the product as ProposalOps, while each page owns its actual page title. This removes duplicate shell/page title presentation without changing routes or module labels.

Representative final page titles are captured in `artifacts/ui-system-closure/visual-qa.json`: Dashboard, Proposal Register, Completion scopes, Engineering Works, Issues across AMEC work, and Administration.

Completion was specifically reconciled: the repeated full-width title strip was reduced to a compact boundary note, the page title remains in the page content, and the empty-state CTA is colocated with the empty-state explanation.
