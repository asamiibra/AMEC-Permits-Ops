# Empty-state system

The shared hierarchy is:

1. restrained icon where useful;
2. clear empty-state title;
3. one or two lines explaining the condition/prerequisite;
4. prerequisite note when it prevents action;
5. CTA inside the empty state or immediately adjacent to the affected collection.

Representative states were reviewed on Completion, Admin, Permit, Dashboard, Engineering, Issues, and sparse list surfaces. They use flat bordered surfaces, concise copy, and no fake records or decorative illustrations.

Completion now states that no scopes exist, that the eligible Construction handoff is the prerequisite, and keeps Start Completion inside the structured empty state. Eligibility and workflow behavior remain unchanged.
