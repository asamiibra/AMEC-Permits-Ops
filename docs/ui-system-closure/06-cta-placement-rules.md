# CTA placement rules

- Page-level collection action: page or collection header.
- First-record action: inside or immediately adjacent to the empty state when the collection is empty.
- Panel action: in the panel header or panel body that it affects.
- Row action: in the row; existing action semantics and labels are preserved.

Applied examples include the Proposal Register `New Proposal` action, Completion `Start Completion`, Engineering review actions, Permit/Authority entry actions, and Issues row actions. No action was added, removed, renamed for business meaning, or rerouted.
