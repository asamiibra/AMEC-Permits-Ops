# Advanced Diagnostics

Advanced Diagnostics is secondary and intentionally not a normal configuration peer. It rehomes attachment/grid diagnostics, control diagnostics, detailed lineage, and adapter diagnostics. The route may expose IDs, hashes, counts, and synthetic fixture evidence; the primary owner screens do not.

The old test extraction, expected results, test analysis, test targets, and test documents surfaces remain internal testing material. They are not presented as owner setup options and are excluded from the normal Administration index.
