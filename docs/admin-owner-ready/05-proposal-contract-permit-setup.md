# Proposal, Contract, and Permit setup

The three setup projections keep commercial and permit configuration legible:

- Proposal Setup shows required intake fields, source types, lifecycle readiness, governed handoff, and provisional-reference behavior.
- Contract Setup shows reference rules, required fields, backend-enforced eligibility, current synthetic Contracts, and Permit-readiness conditions.
- Permit Workflow Setup shows permit types, Municipality mode, requirements, attachment categories, MFA, supported reads/writes, and the human submission boundary.

The projections reuse the Proposal/Contract backend contracts and permit configuration tables. They do not turn internal test targets, extraction fixtures, or closure decisions into owner configuration controls.
