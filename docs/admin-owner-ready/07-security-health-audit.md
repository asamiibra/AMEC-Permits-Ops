# Data, Security & Retention, Integration Health, and Audit History

Security is a projection, not a credential editor. It states data mode, classification, MFA, role-based access, audit retention availability, backup/recovery setup, and a no-secrets assertion. Passwords, tokens, OTPs, database URLs, and authorization headers are excluded.

Integration Health is a business-readable view of the same safe connection health projections. Detailed adapter evidence is available only through Advanced Diagnostics.

Audit History reads operational `AuditEvent` rows and presents actor, event, record, timestamp, and outcome. Technical detail is linked to Advanced Diagnostics, preserving owner readability without hiding lineage.
