# Project & Folder Setup

`GET /api/admin/project-setup` projects the reference rule, seeded scenario, semantic folder mappings, Synology root mapping, folder template version, Excel mapping, and recent project-number reservations.

The displayed rule preserves the lifecycle boundary: a Proposal may begin with a provisional reference; the canonical Project Reference is assigned by the AMEC-controlled project flow; Proposal → Contract → Permit → project folder lineage remains explicit. Missing production numbering and root mappings are shown as setup needs, not invented values.
