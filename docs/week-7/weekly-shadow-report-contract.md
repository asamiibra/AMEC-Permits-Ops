# Weekly Shadow Report Contract

`GET /api/week7/report` returns a deterministic synthetic report with period, fixture/version/hash, cases processed, findings by source/severity, blocking findings, tasks, unassigned work, notifications created/delivered/failed, acknowledgement timing, overdue items, and precheck/official-comment/portal-validation counts.

The report is labeled exactly: **DEMONSTRATION BASELINE — SYNTHETIC DATA — NOT CLIENT APPROVED**.
