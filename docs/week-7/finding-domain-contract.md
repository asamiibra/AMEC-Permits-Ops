# Finding Domain Contract

`Finding` preserves raw text, source language, optional translated summary, source type/reference, authority event, source context, code/version, severity, blocking state, discipline, affected object, requirement, evidence, assignee, due date, status, and correlation ID.

Week 7 statuses are `OPEN`, `ASSIGNED`, `IN_PROGRESS`, `DISPUTED`, and `DEFERRED`. No unrestricted finding-close API or UI action exists. Task completion remains separate from professional/technical finding closure, which is deferred to Week 10.
