# Bilingual / RTL Operator UX

The Week 7 console provides English labels and Arabic operational labels for severity, status, ownership, due date, evidence, and source. A layout toggle enables Arabic/RTL presentation while raw Arabic evidence remains unchanged.

IDs, hashes, references, and mixed Arabic/English evidence use explicit left-to-right or plaintext direction handling so identifiers remain readable inside RTL context. These are operational labels, not legal translations.
