# FindingCode Contract

Finding codes are versioned configuration with bilingual titles/descriptions, allowed source classes, discipline, default severity/blocking behavior, required owner role, provisional SLA, closure-evidence policy, effective dates, and `DRAFT`/`ACTIVE`/`RETIRED` status.

Seeded synthetic codes are `PROPERTY_IDENTITY_MISMATCH`, `OWNER_AUTHORIZATION_MISSING`, `DRAWING_REVISION_MISMATCH`, `ATTACHMENT_MISSING`, `ATTACHMENT_WRONG_CATEGORY`, `PORTAL_REQUIRED_FIELD_MISSING`, `PRECHECK_TECHNICAL_TODO`, `PRECHECK_DOCUMENT_TODO`, `OFFICIAL_DRAWING_COMMENT`, `OFFICIAL_DOCUMENT_COMMENT`, and `OTHER_AUTHORITY_COMMENT`. Retired or source-incompatible codes are not selected for new findings; unknown codes remain reviewable with preserved raw source.
