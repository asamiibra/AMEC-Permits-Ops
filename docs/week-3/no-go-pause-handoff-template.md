# No-Go / Pause Handoff Template

> **DEMONSTRATION BASELINE — SYNTHETIC DATA — NOT CLIENT APPROVED**

Use this template if the human decision is `NO_GO` or `PAUSE`:

- Decision, date, authorized decision maker, and exact reason.
- Blockers and RAID items that caused the decision.
- Data and credential handling confirmation: no real data, credentials, OTPs, payments, signatures, or submissions performed.
- Evidence to preserve: checksumed baseline, audit events, adjudication history, and sanitized export.
- Re-entry criteria, owner, target review date, and next authorized action.
