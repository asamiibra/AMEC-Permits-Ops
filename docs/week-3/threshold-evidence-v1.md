# Threshold Evidence v1

> **DEMONSTRATION BASELINE — SYNTHETIC DATA — NOT CLIENT APPROVED**

Thresholds are stored with metric code, category, observed value, sample size, proposed operator, severity, acceptance effect, status, basis, and notes. The critical-field agreement, classification agreement, candidate extraction, median verification, and false-accept metrics remain `PROPOSED`, `NEEDS_MORE_EVIDENCE`, or `MEASURED`; none is `APPROVED_STAGE_2`.

The API rejects attempts to approve a contractual threshold from synthetic evidence with `SYNTHETIC_EVIDENCE_CANNOT_APPROVE_CONTRACTUAL_THRESHOLD`.
