# Administration owner-sketch history and current state

The repository contains the mature domain generations described by the Owner sketch. Early Opportunity/Quotation compression is retained only as compatibility history; Proposal and its immutable accepted revision are the upstream commercial identity. Administration owns the canonical Contract workspace, while Billing owns the canonical Invoice lifecycle and Administration exposes its operational projection.

Current ownership is: Proposal → accepted Proposal revision → Contract/ContractRevision → human Contract authority → explicit ProjectActivation → canonical Project/ServiceEngagement; finalized ContractRevision → ContractBillingContext → BillingPlan/BillingPlanRevision → BillingMilestone → Invoice/InvoiceRevision → human Accept → controlled Issue/Delivery/Acknowledgment/Approval → Receivable/verified Payment allocation. Handover/Closeout, Setup & Controls, AMEC Work, Issues, Notifications, Audit, and Dashboard master content remain separate domains.
