# Final Administration information architecture

Administration opens on a simple operational view: Contracts and Invoices are the primary workspaces. Handover & Closeout and Setup & Controls are secondary links. AMEC Work remains the task queue; Issues remain blockers/findings; Notifications remain event delivery; Dashboard remains reusable master/reference content.

The primary register is intentionally compact. Rich lineage, revisions, authority, activation, billing, evidence, and history remain in detail workspaces.
