# Synology storage runbook

Before activation, configure the approved real Synology endpoint, least-privilege service account, root path, TLS/network policy, and retention rules. Execute write/read-back/hash, permission-denial, recovery, and concurrent-access rehearsals. The audited adapter was `MockSynologyAdapter`; `REAL_SYNOLOGY_VERIFIED` is withheld. Storage Owner and endpoint: `OWNER_INPUT_REQUIRED`.
