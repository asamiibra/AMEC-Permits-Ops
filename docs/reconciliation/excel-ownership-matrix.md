# Excel Ownership Matrix

> **DEMONSTRATION BASELINE — SYNTHETIC DATA — NOT CLIENT APPROVED**

Canonical human sheets: `GENERAL FOLLOW UP`, `DESIGN`, `Suppervission`, and `Services Provider`. `Project Number` is an exact row key; sheet and row number are retained in `ExcelProjectRow`.

Human-owned columns include client/owner, status, human notes, design lead, supervisor, provider, and service notes. PermitOps-owned columns exist only in `PERMITOPS SYSTEM PROJECTION`: canonical plot, canonical PIN, rendering version, municipality request, and projection status. Authority-derived values remain read-only references.
