# Target Rendering Foundation

> **DEMONSTRATION BASELINE — SYNTHETIC DATA — NOT CLIENT APPROVED**

`TargetRenderingRule` separates raw observation, canonical verified semantic value, and target presentation. The seeded plot-number rules render the same canonical value for FORM, EXCEL, and MUNICIPALITY with version `1.0`; area and permit-type code-map examples demonstrate deterministic formatting and dropdown mapping.

Rendering is implemented in a backend service, not in React components, and no LLM selects a critical target code.
