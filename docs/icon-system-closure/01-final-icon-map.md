| Icon name | Lucide component | Use |
| --- | --- | --- |

| `construction` | `HardHat` | Construction navigation |
| `completion` | `BadgeCheck` | Completion navigation |
| `permit` | `FileCheck2` | Permit navigation |
| `contract` | `FileSignature` | Contract document surfaces |
| `handover` | `PackageCheck` | Handover package surfaces |
| `authority` | `Landmark` | Authority Cases navigation |

| `settings` | `Settings` | Administration navigation |

| `shield` | `ShieldCheck` | Integrity, permission, and provenance states |
| `check` | `CircleCheck` | Confirmed or complete state |
| `alert` | `CircleAlert` | Blocker, warning, or attention state |
| `empty` | `ClipboardList` | Truthful empty state |
| `finance` | `CircleDollarSign` | Finance context |

The semantic arrows and separators that remain in explanatory copy are text, not icon controls. They are not counted as navigation icons or action glyphs.
