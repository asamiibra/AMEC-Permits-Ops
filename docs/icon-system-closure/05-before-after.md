# Before / after

| Before | After | Applied to |
| --- | --- | --- |
| Unicode check, warning, plus, close, and back glyphs | Lucide `CircleCheck`, `CircleAlert`, `Plus`, `X`, and `ArrowLeft` | States and controls across deep surfaces |
| Text `Open →` action treatment | `Open` label with `ArrowUpRight` icon | Open/detail actions |
| Mixed hand-authored SVG/icon treatment | One `Icon` wrapper backed by Lucide React | Navigation and supporting actions |
| CSS pseudo-element check/bullet markers | Explicit semantic `Icon` elements | Operating Guide AI cards |
| Unaligned nav glyphs | Fixed 22px slot with centered 18px SVG | All sidebar items |

Labels and interaction semantics remain unchanged. The visual change is limited to how icons are drawn, sized, aligned, and exposed to assistive technology.
