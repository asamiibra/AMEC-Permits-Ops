# Source and action contract

Tender Email, Tender Document, Tender Photo / Image, and Client Information create or add retained Proposal source evidence. Each card opens a focused modal; additional sources are secondary.

Client List reconciles the Client master and never creates or opportunistically binds a Proposal. Proposal Form requires an existing eligible Proposal and Project. Contract Form requires an existing Contract, related Proposal, and Project. All uploads use styled manual file selection and report read-back verification only after the backend confirms storage.
