# Owner Sketch 14 Gap Matrix

| Sketch concept | Safe executable interpretation |
|---|---|
| Owner | Canonical Owner/Applicant Party role and authorized business action |
| Consultant | Scoped Consultant Party role plus professional assignment/credential |
| Contractor | Scoped Contractor Party role |
| As Built | AS_BUILT BuildingSnapshot and AsBuiltBaseline, not a filename/folder |
| Approved | Explicit professional approval or precise human acceptance action; never automatic authority approval |
| Drawing As Built | EngineeringDeliverableRevision and exact DocumentVersion/Rendition |
| Forms Automatic | Governed AUTOMATED_USE_READY generation only; no automatic sign/stamp/submit |
| Report Automatic | Deterministic RenderedArtifact output pinned to source/template/hash |
| Accept | Explicit baseline/report/preparation human action, never generic accepted state |
| Proceed | Move to the next eligible validated step, never authority approval |

Visible app roles remain Owner, Business Development, and Engineering. Consultant and Contractor are scoped Party roles, not new application roles.
