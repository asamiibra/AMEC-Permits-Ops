# Source Readiness

Code-level governed source reuse is available through Dashboard MasterContent, DocumentVersion, FormAutomationProfile, MappingRelease, FormInstance, SignaturePacket, and RenderedArtifact. Production Completion submission remains blocked where clean/current masters or policy cannot be independently certified.

Applicable truthful blockers are: Completion Form source, Building Statistics source/mapping, Materials Conformity source/policy, Site Cleanliness source where an AMEC declaration is required, and Authority Policy Currentness. Filled/project-specific signed examples are restricted/reference samples, not production blanks. The code freeze can be earned independently of these external production-source blockers.
