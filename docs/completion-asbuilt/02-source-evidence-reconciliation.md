# Source Evidence Reconciliation

The supplied source patterns are treated as capability evidence, not current policy: service approvals by building type, Building Permit reuse, owner/applicant identity, consultant-stamped As-Built drawings, Building Statistics, materials/specification conformity, site photos and exterior paint samples, survey/site actions, site-cleanliness certificates, paper true copies, and multiple electronic copies.

The AMEC client collection checklist remains distinct from authority submission policy. The repository contains no clean/current Completion source corpus that can be certified as a production master for the supplied filled/project-specific examples. Runtime RequirementPolicyVersion and governed Dashboard Forms/Reports content therefore remain the only valid policy/source path. Missing current sources are recorded as production blockers, not erased by automation.

Hard distinctions preserved: internal declaration versus authority-issued site-cleanliness certificate; Survey Report versus Property Plan versus Land Demarcation versus Survey-Mark Restoration; digital paint photo versus PhysicalEvidenceItem; MaterialTestRecords versus conformity certificate; and DocumentVersion presence versus requirement satisfaction.
