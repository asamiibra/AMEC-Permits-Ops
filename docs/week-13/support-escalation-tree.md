# Support escalation tree

- **L1 — Client Super-user / Process Champion:** user/process questions, basic data/package triage, routing, progress visibility. Cannot alter professional closure or bypass gates.
- **L2 — PermitOps / Arkan Support:** application defects, configuration, OCR behavior, portal/read-adapter drift, notification/monitoring defects, technical troubleshooting. Cannot make professional decisions.
- **L3 — External Dependency:** Ministry/authority behavior or outage, cloud/OCR/model/vendor infrastructure, Synology or Microsoft tenant issues outside PermitOps.

`SupportCase` is bounded and retains severity, level, correlation, related Finding/monitoring run, external dependency, and resolution state.
