# Source card context contract

Tender Email, Tender Document, Tender Image, and Client Information create or extend Proposal intake context through the intake SOR. Client List writes a project source and does not auto-create a Proposal. Proposal Form requires a resolvable Proposal/project lineage. Contract Form requires a resolvable controlling Contract and matching Proposal/project lineage.

All writes require a manually selected file, target resolution, idempotency/read-back verification, and persisted provenance.
