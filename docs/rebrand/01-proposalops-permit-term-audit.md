# ProposalOps visible-term audit

The active shell, document title, API public metadata, Operating Guide, production-readiness registry, and unified work panel were updated to ProposalOps terminology. A runtime naming boundary also rewrites legacy labels emitted by older workflow components so active user-facing surfaces remain consistent while internal identifiers remain stable.

Allowed compatibility terms include database/API identifiers, legacy route parsing, historical evidence, and external Municipality/Authority terminology. The remaining source-level legacy terms are tracked as compatibility debt; they are not evidence of a user-facing product label after the runtime surface is applied.
