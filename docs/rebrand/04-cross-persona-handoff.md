# Cross-persona handoff

The handoff path is shared-record based: Business Development creates or advances commercial context; Engineering opens the same proposal record for technical preparation; Owner can review the full state, blockers, evidence, and audit history. Tasks, issues, notifications, and deep links remain tied to the canonical project/application record rather than copied between persona-specific stores.

The current implementation keeps the synthetic human-submission boundary: ProposalOps prepares and records evidence, while an authorized human performs any Municipality submission.
