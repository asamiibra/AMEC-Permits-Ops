# Work, Issues, and Notifications boundary

AMEC Work answers what a person must do now. Issues owns what is blocking, wrong, or at risk. Notifications owns what changed or should be known.

An authority status change with no action remains a recent notification. An assigned authority Finding projects to work and remains linked to issue context. A communication draft needing human review or send projects as a readable work item; raw draft enums are not rendered. Reading a notification does not complete the underlying work item. Failed delivery is actionable only when the existing delivery state offers a human retry or reroute action.
