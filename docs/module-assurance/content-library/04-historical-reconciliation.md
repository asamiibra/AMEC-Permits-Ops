# Historical Reconciliation

The historical census covered 18 `branch/content-library-*` branches and the step-2 through step-5 Content Library records. The surviving semantic work was already present in the current branch: Dashboard discovery, canonical retrieval, module/purpose bindings, exact version pinning, lineage, consumer resolution, owner-product behavior, and governed prefill boundaries.

Historical implementation-only or superseded material includes Azure/preprod deployment attempts, commissioning preparation, duplicate downstream consumer prototypes, and older template/definition demos. These were not cherry-picked wholesale. They were classified against current ownership and retained only where the behavior is represented by current code or evidence.

Result: no historical branch is an independent authority, no release branch was changed, and no migration was inferred from historical code alone.
