# Project Evidence Seam

Evidence ownership is split across the Evidence chain (`FieldDefinition`, `FieldObservation`, `VerifiedAssertion`, `FieldAuthorityRule`, `RequirementConfig`) and preparation/submission (`CaseEvidenceSelection`, `PhysicalEvidenceItem`, `SubmissionPackageItem`).

Content Library sources may be selected/cited through governed consumer seams, with exact source document/version references. A reusable source is not a Project Evidence item, observation, verification, assertion, or submission artifact. No direct Content Library write path creates project evidence truth.
