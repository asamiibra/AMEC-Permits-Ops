# Boundaries and security

- Proposal truth remains separate from Contract truth and Project Activation.
- Client acceptance is evidence, not AMEC Proposal Accept.
- Contract eligibility is not legal contract execution.
- No AuthorityCase, regulatory journey, production release, invoice, or project activation is created by this module.
- Human role capabilities are enforced at each protected transition.
- Synthetic mode and test-only evidence are explicit; no real client or AMEC data is used.
