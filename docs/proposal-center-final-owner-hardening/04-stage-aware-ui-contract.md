# Stage-aware UI contract

Stages render as past, current, or future. Past sections are preserved and read-only; the current section is actionable for the current owner; future sections are locked previews. Engineering Preparation is the only active work surface for the golden Engineering fixture. Client Response, Commercial Outcome, Review / Authority, Accept, Contract, and output actions are not active there.

The backend remains authoritative. UI locking is progressive disclosure and does not replace server-side command gates.
