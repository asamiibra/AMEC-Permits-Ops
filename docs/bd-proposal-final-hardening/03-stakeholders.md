# Stakeholders

`ProposalStakeholderIntent` records known/candidate roles with optional canonical Party linkage, display snapshot, status, source, and note. A name does not create a Party. Proposal intent is kept separate from case-role assignment, applicant identity, legal signatory, and AuthorityCase roles.

The Owner UI exposes role, unresolved description, status, and the boundary copy “Proposal intent only · no case-role assignment.”
