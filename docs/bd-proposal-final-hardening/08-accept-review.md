# Accept Review

The Owner workspace includes one concise Accept Review projection covering client/contact, site/property, AMEC scope, regulatory intent, commercial values, assumptions/unknowns/conflicts, expected inputs, Dashboard template/checklist readiness, source freshness, and authority.

Accept takes the current revision only after validation, material acknowledgment, and staleness review. It records an immutable Accepted Proposal revision and output lineage; it never auto-creates a Contract or AuthorityCase.
