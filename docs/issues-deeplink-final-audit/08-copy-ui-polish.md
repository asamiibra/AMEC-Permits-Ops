# Copy and UI polish

Owner-facing click paths use Proposal, Contract, Permit, Source evidence, Verified, Current, and business-role action labels. Internal fixture identifiers, synthetic evidence URIs, raw hashes, SOR implementation names, and generic “Open record” copy are excluded from normal Issue and target surfaces.

Proposal and Contract pages use structured cards/grids rather than concatenated labels. Commercial pages do not display Permit-specific “no portal writes” warnings. Empty provenance uses an explicit business empty state.
