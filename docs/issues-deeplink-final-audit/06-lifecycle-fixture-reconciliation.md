# Lifecycle and fixture reconciliation

The synthetic demo uses separate coherent records: an active Proposal Preparation record, a contracted Proposal/Contract chain, a source-confirmation Permit, and a returned Authority/Corrections Permit. Authority findings no longer sit on the never-submitted Verify-stage application.

Technical findings, workflow tasks, notifications, projects, proposals, contracts, and applications are remapped to their intended target records during seed reconciliation. Preparation copy is professional and accidental garbage text is absent.
