# Owner change contract

ProposalOps owns the business-facing Dashboard at `/dashboard`. It exposes four maintained areas: Forms, Reports, Engineering Works, and Definitions. Forms, Reports, and Engineering Works use the configured SOR for authoritative bytes; Definitions are structured database semantics. Normal users receive business-safe storage status and never select or see a physical SOR path.

The existing AMEC Work surface remains the operational work queue and the existing Proposal → Contract → Permit lifecycle remains separate.
