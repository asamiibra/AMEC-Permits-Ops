# Dashboard UI contract

`DashboardPage` renders four owner-recognizable sections with database-backed search and category filtering. Tables expose business fields only. Owner mode gets New/Modify controls; other personas can read and open content but cannot mutate globally. Upload feedback uses business language such as “Verifying storage”. Errors show retry rather than a fake empty state. Version history shows business-safe version, status, file name, reason, actor, and date.
