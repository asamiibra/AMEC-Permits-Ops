# Proposal handoff

The accepted Proposal revision is a hard, immutable Contract input. The focused PostgreSQL regression verifies revision pinning, exact origin metadata, checklist/template lineage, no silent resynchronization after a later Proposal revision, and no Proposal history rewrite.

Result tokens: `CONTRACT_EXACT_PROPOSAL_REVISION_PASS`, `PROPOSAL_POST_CONTRACT_SILENT_RESYNC_ZERO`, `PROPOSAL_HISTORY_REWRITE_ZERO`.
