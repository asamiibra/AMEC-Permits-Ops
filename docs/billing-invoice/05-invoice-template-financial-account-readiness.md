# Template and financial-account readiness

The external sample invoice is `REFERENCE_ONLY` and unavailable in this checkout. Invoice rendering therefore uses the existing governed `RenderedArtifact`/`TemplateVersion` foundation and records exact template version/profile metadata; it does not mutate or promote the sample. Financial accounts are versioned protected configuration. Raw bank/IBAN values are never returned in broad read models, audit payloads, or AI context; issued invoices pin only the exact FinancialAccountVersion ID.
