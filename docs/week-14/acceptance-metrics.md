# Acceptance metrics

The acceptance runner records sample size, evidence class, threshold status, and result for classification, extraction, verified critical fields, false accepts, manual keyed rate, timing, attachment/grid mapping, persistence, portal reconciliation, monitoring, dedupe, Finding/task/notification, closure evidence, recurrence, resubmission escapes, and operator friction.

All numeric thresholds are `NOT_APPROVED` except zero-tolerance safety invariants, which are enforced as zero.
