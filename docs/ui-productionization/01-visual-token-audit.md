# Visual token audit

The existing palette and typography were retained. A final override layer reconciles the existing styles around shared tokens for spacing, neutral surfaces, borders, focus, controls, and operational density.

Token rhythm used: 4 / 8 / 12 / 16 / 20 / 24px. Control radius is 6px; standard surface radius is 8px. Normal operational surfaces use borders instead of elevation. Popovers and drawers retain meaningful elevation.
