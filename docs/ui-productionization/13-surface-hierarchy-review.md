# Surface hierarchy review

The Dashboard no longer uses a large shadowed container for every operational layer. Overview, library navigation, filter toolbar, and Forms sections retain semantic grouping but use restrained borders, 7–8px radii, reduced padding, and no normal elevation. Table wrappers remain necessary for overflow and are visually subordinate to the table itself.

Dialogs, drawers, and popovers retain elevation because they are layered interaction surfaces.
