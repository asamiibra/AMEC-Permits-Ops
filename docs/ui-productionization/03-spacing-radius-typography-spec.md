# Spacing, radius, and typography

Page content now uses 24px vertical / 28px horizontal desktop padding and 16px / 14px at small widths. Dashboard sections use 14px padding and 14px vertical separation. Page titles are 26–28px, section headings 16–18px, body text 13–14px, and metadata 10–12px.

Large decorative radii and shadows were reduced. Fully rounded treatment remains limited to semantically appropriate status or count elements.
