# G5 — Registers and KPIs

The shared page has Proposals and Contracts tabs. Proposal columns are Proposal Description, Project Ref., Stage / Status, Amount, Last Activity, and Actions. Contract columns are Contract, Contract Ref., Related Proposal, Amount, Last Activity, End Date, and Actions.

The six KPI values are computed from deterministic state predicates in the API and filter the corresponding register. Last Activity uses domain timestamps, not page views.
