# G4 — Proposal Preparation

Proceed changes the same Opportunity/Proposal to `PROPOSAL_PREPARATION` and creates one BD → Engineering WorkflowTask and AssistantHandoff. Proposal Preparation exposes verified sources, SOW, Process of Work, technical exclusions, Period, and readiness. Engineering-ready changes the same Proposal to `PROPOSAL_HANDOVER` and creates the Engineering → BD handoff.

No duplicate Proposal record is created during either handoff.
