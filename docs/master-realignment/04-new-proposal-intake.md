# G3 — New Proposal intake

New Proposal is source-driven and supports Tender Email, Tender Document, Tender Photo / Image, and Client Information, including multiple sources on one Proposal. Price, SOW, Period, and Exclusions are captured as governed Proposal fields with provenance retained in the Opportunity record and source evidence.

The Proceed gate evaluates Proposal existence, source evidence, Client context, description, and known reference state. It returns exact missing requirements and does not create Engineering work on failure.
