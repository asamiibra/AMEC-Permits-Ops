# External comment seam

The current canonical external record is `AuthorityCaseFinding`. Engineering can expose the seam and link a project-matching finding to the exact revision and Review Category. Engineering cannot create or close the finding. The link produces lineage to the revision; a design change is explicit and does not automatically create a new revision or approval.

Required downstream statement: `ENGINEERING_EXTERNAL_AUTHORITY_COMMENT_SEAM_COMPATIBLE_WITH_AUTHORITY_FINDING`.
