# AMEC setup-item registry

`ProductionRequirement` is the shared model used by every screen. Categories cover data sources, access, permissions, roles, business rules, templates, mappings, security/privacy, regulations, communications, people/support, scale, test data, and go-live support.

The same setup item can apply to many screens through `appliesToScreenIds`; page-local copies are prohibited. Setup state is deliberately descriptive. The current environment remains a synthetic prototype.
