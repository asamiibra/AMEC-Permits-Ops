# Data sources and access

The go-live setup checklist calls for a Synology project location, Project Excel workbook, owner/property evidence, real sample documents, Municipality status source, project file/network access, account/read access, and a selected working mode.

Safe defaults are explicit: synthetic source links/workbooks/documents, no production file access, and assisted/manual Municipality capture. No credential, QID, title deed, or authority write is implied by the UI.
