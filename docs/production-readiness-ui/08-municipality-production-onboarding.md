# Municipality production onboarding

Municipality onboarding is a separate evidence track: account ownership, read access, supported status source, interaction mode, portal semantics, page sequence, field/dropdown/grid/attachment mappings, MFA/session behavior, read-back, reconciliation, drift handling, and human submission authority.

The product supports an Assisted fallback. It does not auto-submit, bypass MFA, or turn a draft/handoff into an official submission.
