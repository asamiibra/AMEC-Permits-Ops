# Definitions consumption

BD receives current active Definition entries bound to BD, including the exact current DefinitionRevision ID and revision number. The Proposal value remains transactional and source/manual-provenance controlled. Definitions are not executable regulatory policy and are not copied into a BD master table.

Unresolved, archived, or unavailable Definitions are not silently fabricated. The configuration panel reports semantic-definition availability separately from client values and expected-input policy previews.
