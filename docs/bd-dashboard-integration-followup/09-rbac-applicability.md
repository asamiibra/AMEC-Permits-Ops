# RBAC and applicability

Role, module/purpose binding, currentness/readiness, and applicability remain distinct. BD can read/use applicable content but has no global master-content write capability. Engineering can consume its applicable references but has no global master write capability. Owner/Admin retain management capabilities.

Negative coverage includes BD global write denial, permit-only content excluded from the BD Proposal Template resolver, and Engineering-reference deferral before preparation.
