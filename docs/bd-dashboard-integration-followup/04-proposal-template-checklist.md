# Proposal Template and Checklist

The Proposal configuration panel reads the Dashboard resolver projection and displays the exact reference, version, hash, purpose, and canonical identity. BD has no global master-content write control. Missing or conflicting configuration is shown as Owner confirmation/configuration attention and does not block initial Stage 1 intake; final validation and acceptance enforce the existing template/checklist policy.

Accepted revisions already persist `master_content_id`/reference, exact `DocumentVersion` ID, version number, and hash for both template and checklist. Generated artifacts carry the accepted revision and exact version lineage.
