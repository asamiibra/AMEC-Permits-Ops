# Authority boundary

Dashboard remains the canonical AMEC master/reference layer: Forms, Reports, Engineering Works, and Definitions. BD / Proposal owns one client-specific transaction, its source evidence, notes, client request, lifecycle, and accepted outputs. Client / Party records remain business-domain records. No Dashboard client library or duplicate BD master tables were added.

Proposal sources are transactional evidence and are never promoted to Dashboard automatically. Accepted Proposal revisions retain exact master-content identities and hashes.
