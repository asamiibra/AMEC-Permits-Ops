# Accept, downloads, and handoff

Human Accept is capability-protected and blocked while validation has blockers. A successful Accept stores an immutable revision snapshot with actor/time, AMEC Input, source ids, commercial fields, Dashboard template/checklist version and hash, and definition references. Engineering Accept returned 403 in local PostgreSQL and deployed API checks. Proposal and Checklist artifacts are hash-verified and lineage-bound to the accepted revision; history uses revision-specific artifact rows, so prior outputs are not overwritten. Explicit Contract handoff preserves the exact accepted revision and is marked `machine_legal_contract: false`.
