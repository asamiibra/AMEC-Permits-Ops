# Persona action matrix

| Persona | Permit Stage 1 | Proposal intake | Proposal lifecycle | Engineering handoff | Commercial amount |
|---|---|---|---|---|---|
| Owner | Confirm command allowed | Manual sources allowed | View/proceed/contract as governed | View | Visible |
| Business Development | Confirm command allowed | Commercial source actions | Commercial lifecycle actions | View handoff | Visible |
| Engineering | Confirm command allowed | Engineering-visible source actions | Proposal preparation / ready-for-BD | Owns technical handoff | Hidden |
| Final Submitter | Not allowed by Stage 1 command | Not applicable | Not applicable | Human portal submission only | Not applicable |
| System Admin | Confirm command allowed | All synthetic controls | All bounded synthetic controls | Administrative visibility | Visible |

Role checks are enforced server-side for the Stage 1 command. UI persona selection is not treated as authorization.
