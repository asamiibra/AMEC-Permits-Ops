# Entry baseline

Repository: ProposalOps / AMEC workspace.

The baseline shell had a flat sidebar with Dashboard, My Work, BD, Engineering, Construction, Completion, Permit, Authority Cases, Issues, and Notifications. `/dashboard` was the canonical master/reference-content surface, while `/work` was the AMEC Work deep link. Notifications already had canonical list, summary, acknowledgement, and deep-link APIs.

This change is limited to information architecture, Home composition, header controls, route naming, and regression coverage. Domain models and resolver behavior are preserved.
