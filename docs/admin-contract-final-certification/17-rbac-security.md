# RBAC and Security

Owner/SYSTEM_ADMIN can operate Administration and Contract actions. Commercial and Engineering personas cannot retain privileged Administration access; denied actions return controlled authorization responses. Document access, Contract actions, Billing roles, Project Activation, and Handover commands are role-scoped.

Cross-project context guards and persona route matrix checks passed in the full backend/browser evidence. Production identity, MFA, secrets, and external authorization infrastructure remain outside synthetic certification.
