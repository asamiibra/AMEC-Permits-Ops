# Owner Input Required

The software seams are present, but the following require Owner decisions or official content: standalone/manual Contract policy; official Contract template and language; authority/signing thresholds; PIN semantics; LPO requiredness and document requirement policy; final Deliverable policy; Project code assignment and start-date semantics; official invoice template, numbering, financial-account, payment, and settlement policy; production users/roles; and official retention/notification policy.

These are not silently defaulted into legal or production truth. Where a safe synthetic fallback exists it is labeled and remains non-authoritative.
