# ProposalOps owner model

The latest owner direction defines ProposalOps as the commercial collection for two linked registers: Proposals and Contracts. Permit remains a legitimate downstream domain term for Permit Application, Permit Workspace, Municipality Preparation, Permit Submission, Authority Review, and Permit Findings. The lifecycle anchor is one Project and Project Reference carried from source intake through Proposal, Contract, and PermitApplication.

The UI therefore uses separate register tabs, shared KPI state, manual source controls, and human-controlled row transitions. The existing permit workspace and its safety boundaries remain downstream.
