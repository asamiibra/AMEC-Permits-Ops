# Evidence and Intelligence UX contract

Evidence is shown as records, not type-existence cards. Each Evidence Center row keeps source family, source title, verification/currentness state, DocumentVersion or source revision, and date visible. Human notes, unknowns, conflicts, assumptions, and machine observations remain distinct.

The shared Intelligence renderer supports:

- candidate assertions with candidate trust state, producer, confidence, and provenance copy;
- current, stale, and invalid work-product states;
- citation lists with evidence locators;
- a read-only unavailable boundary when no executable Proposal skill is registered.

The P04 environment has no real Proposal skill/provider, so no Analyze, Generate, Ask AI, or chat action is rendered and no machine output is invented. Intelligence cannot authorize acceptance, release, distribution, client acceptance verification, LPO reconciliation, or Contract handoff.
