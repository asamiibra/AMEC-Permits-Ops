# Technical, scope, and eligibility proof

Technical assessment writes accept assessment type, PASS/CONDITIONAL/BLOCKED/INCOMPLETE result, findings, assumptions, and exact DocumentVersion IDs. Scope confirmation consumes the latest acceptable assessment and explicit service offering codes. The UI no longer submits a fixed PASS or PERMITTING value.

Eligibility remains a protected backend command and is recorded per explicit offering. The service catalog/capability and regulated qualification evidence remain server-owned; no Proposal AI action is fabricated.
