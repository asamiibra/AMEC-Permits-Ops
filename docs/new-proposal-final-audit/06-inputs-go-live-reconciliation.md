# Inputs & Go-Live reconciliation

New Proposal has readiness screen `S02A` and route `/proposals/new`. Its drawer title, purpose, inputs, outputs, unresolved count, and business wording are route-specific. Parent portfolio metadata and primary Municipality/Permit requirements are excluded from this drawer.

The drawer uses `Demo ready · N go-live inputs remaining` and preserves the existing View details control. Downstream Permit setup remains available on Permit surfaces.
