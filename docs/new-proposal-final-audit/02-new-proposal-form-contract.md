# New Proposal form contract

The dedicated form is one shared component used by generic New Proposal and source-card entry. It contains Proposal Description, Client, optional Project context, Price, Period, Initial SOW / Tender Scope, Exclusions, source evidence, and the mutation CTA `Create Proposal & Save Sources`.

At least one source file is required. Proceed is intentionally absent from creation and remains a separate backend lifecycle command on Proposal Detail.
